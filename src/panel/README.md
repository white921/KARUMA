# パネルの配置

パネルの表示内容、ボタンの構築、投稿処理を機能別フォルダーで管理する。
`currency` は銀行、`hotel` はホテル、`game` は遊戯、`market` は市場・紋章・スパチャ、
`vc` は共通VC・狭間・独房のパネルを扱う。

`panelInstallService.ts` はチャンネルから対象パネルを選び、各機能の設置処理を呼ぶ。
ボタン押下の振り分けは `handler/interaction`、購入・送金などの処理は `service` に置く。
固定の文言や識別子は `constant`、型は `type` から直接参照する。

全体の配置ルールは [ソースコードの配置](../README.md) を参照する。
