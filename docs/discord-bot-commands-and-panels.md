# LEVELIA Bot コマンド・パネル案内

## はじめに

- `LIA` を使う操作やパネルのボタン操作には、原則として **口座開設** が必要です。
- パネルの設置は、**システム管理** が対象チャンネルで `/panel` を実行します。
- パネルはチャンネル権限も適用されます。見えない・押せない場合は、各チャンネルの権限を確認してください。

---

## 全員向けコマンド

### 口座・LIA

口座開設は管理者の `/口座発行` または面接通過処理で行います。旧 `/open_account` は廃止しました。

**`/残高確認`**：口座があれば誰でも自分のLIA残高を確認できます。ユーザー欄で自分を指定した場合も同じです。銀行パネルの「残高確認」も利用できます。

**`/送金 ユーザー 金額 [備考]`**：指定したユーザーへ LIA を送ります。

> 口座と十分な残高が必要です。

---

## 管理・VCコマンド

以下の管理操作は **英傑・皇帝・システム支配人のみ** 使用できます。自分の残高確認は口座があれば誰でも使用できます。

| コマンド | 内容 |
| --- | --- |
| `/残高統計` | 在籍中のメイン口座の平均値・中央値。Bot・サブ垢と、ちょうど30,000LIAの口座を除外します。 |
| `/口座発行 [ユーザー] [ロール]` | どちらか一方を指定して開設。旧 `/admin_open_account` を置き換えます。 |
| `/出戻り target_member` | 対象者の退出前のロール・残高・退出日・出戻り回数などを確認。対象者の口座が必要です。 |
| `/残高確認 [ユーザー]` | 他人の残高は管理3ロール限定。省略時または自分を指定した場合は、口座があれば誰でも確認可能。 |
| `/チケット付与 ユーザー 種類 枚数 理由` | 口座を持つメイン垢にチケットを付与。8種類から選択します。 |

**`/インチャ掃除`**：参加中のVCのインチャで実行し、操作パネル・Botの期限案内・ピン留めを残して掃除します。実行後の新着メッセージも残します。

共用VCでは **貴族・英傑・皇帝・システム支配人**、Bot作成の部屋では **部屋主・英傑・皇帝・システム支配人** が使用できます。大量の古いメッセージがある場合は、2分で一旦区切り、再実行を案内します。

## 全員向けパネル機能

### 双璧戦 競技エントリーシート

`競技エントリー`スレッドのパネルから、所属チームのメンバーが競技ごとの出場可否と、そのタイトルで実際に使うランク・公開名・共有用ID・備考を回答します。回答には紅組または蒼組のチームロールが必要です。

- 「回答・編集」：9競技から選んで回答します。同じ競技は何度でも上書きできます。
- 「回答確認」：自分の全競技の回答と未回答を本人限定で確認します。
- 歌の出場区分（♂・♀）はDiscordロールから自動取得し、本人には入力させません。
- UNITEはランク・トレーナー名・トレーナーID、雀魂は段位・ゲーム内ネーム・プレイヤーIDを入力します。
- VALORANTとLoLはゲーム名とタグラインを分けず、完全なRiot IDを入力します。
- Fall GuysはRanked Knockoutのランクと利用機種上の表示名を入力し、非公開のEpic GamesアカウントIDは収集しません。
- GFは決闘レーティングと預言者の名前、Minecraftはエディションに対応するJavaプロフィール名または統合版ゲーマータグを入力します。
- 回答は出場確定ではなく、大将・副大将が編成に利用します。

紅組・蒼組の大将と副大将は、`/対抗戦回答出力` で自チームの回答だけをGoogleスプレッドシート取込用CSVとして取得できます。相手チームの回答は出力できません。

## チケット換金

チャンネル `1550818163699093574`（チケット換金所）で、同じ種類のチケットを5枚単位でLIAに換金できます。
「チケット換金」→種類選択→「−5枚」「＋5枚」で枚数調整→受取額確認→「換金を確定」の順に操作します。

| チケット | 1枚あたり | 5枚あたり |
| --- | ---: | ---: |
| VIPホテル無料券（12時間） | 3,000 LIA | 15,000 LIA |
| フリーダム無料券（12時間） | 5,000 LIA | 25,000 LIA |
| 遊戯チケット | 300 LIA | 1,500 LIA |
| 市場割引券 5%OFF | 500 LIA | 2,500 LIA |
| 市場割引券 10%OFF | 1,000 LIA | 5,000 LIA |

ホテル・遊戯券は通常料金（遊戯は6人コース）の10%です。市場割引券は固定額面がないため、10,000 LIAの商品に使った場合の割引額を換金額としています。
最初は5枚から始まり、ボタンで5枚ずつ増減します。「最大枚数」は所持数以下の5の倍数（最大100,000枚）を選択します。所持数・換金枚数・受取額はEmbed内の項目に分けて表示し、同じ画面で更新されます。
異なる種類の合算は不可。1回の上限は100,000枚、操作の有効期限は10分です。Bot再起動後はパネルからやり直してください。確定前ならキャンセルできますが、確定後は戻せません。
枚数調整中はDBを更新しません。連打は順番に処理し、古い枚数表示からの確定は再確認を求めます。換金時に所持数を再確認し、チケット消費・LIA発行・取引履歴を同じトランザクションで保存します。凍結口座は利用できません。
同じ確認ボタンを再実行しても追加の消費・入金は発生しません。Bot口座からの引き落としはありません。
換金確定時には「チケット換金ログ」スレッド（`1550824492194857071`）に、換金者・チケット名・枚数・受取額・換金IDを記録します。同じ確認からログを重複投稿しません。Discordへのログ送信が失敗しても換金は確定済みで、DB履歴と運用ログから確認できます。

### 会議VC作成パネル

- 設置先: `1553601403262337044`。`/panel` で再設置可能（既存メッセージを更新）。
