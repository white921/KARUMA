# 📖 LEVELIA日記の使い方

日記フォーラムに、自分用の日記スレッドを作れます。作成後は、そのスレッドに投稿して日記を続けてください。

## はじめる前に

- 日記の作成には、LEVELIA銀行の口座が必要です。
- 日記は1人につき1つまでです。利用中の日記がある場合、新しく追加では作れません。
- サブアカウントは、日記の作成・VIP化・再開・作り直しを行えません。

## 作り方

1. 日記パネルで **「日記を作成」** を押します。
2. 日記のタイトルと、最初に投稿したい本文を入力します。本文は空欄でも大丈夫です。
3. 内容を確認して、表示される確認ボタンを押します。
4. 作成された日記スレッドを開き、これからの投稿はそのスレッドに送ります。

## 利用料金

- 日記は全員一律 **5,000LIA** です。
- 無料作成の対象ロールは設定していません。

## 日記を作り直す

1. 日記パネルの **「日記を作り直す」** を押します。
2. 新しいタイトルと最初の本文を入力します。
3. 削除される元の日記を確認し、**「5,000 LIAで作り直す」** を押します。

通常／VIPの種類を引き継いだ新しい日記を作り、元のスレッドと投稿をすべて削除します。投稿内容は引き継がれず、削除は取り消せません。クローズ済みの日記も作り直せます。

作成や支払いに失敗した場合は元の日記を残します。支払い完了後に元の日記の削除だけ失敗した場合は、自動で再試行します。追加料金はかかりません。

## 3日間投稿がない場合

作成者本人または紐づけ済みのサブアカウントから **3日間投稿がない** 日記は、自動でクローズされます。

もう一度使いたいときは、日記パネルで **「日記を作成」** を選び、タイトルと本文を入力して確定してください。同じ日記スレッドを **5,000LIA** で再開できます。

## 困ったとき

- 残高が足りない場合は、日記を作成・再開できません。
