# 📖 日記の使い方

日記フォーラムに、自分用の日記スレッドを作れます。作成後は、そのスレッドに投稿して日記を続けてください。

## はじめる前に

- 日記の作成には、教団銀行の口座が必要です。
- 日記は1人につき1つまでです。利用中の日記がある場合、新しく追加では作れません。
- サブアカウントは、日記の作成・VIP化・再開を行えません。

## 作り方

1. 日記パネルで **「通常日記」** または **「VIP日記」** を押します。
2. 日記のタイトルと、最初に投稿したい本文を入力します。本文は空欄でも大丈夫です。
3. 内容を確認して、表示される確認ボタンを押します。
4. 作成された日記スレッドを開き、これからの投稿はそのスレッドに送ります。

## 日記の種類

### 🔒 通常日記 — 5,000krm

- スレッド名に 🔒 が付きます。
- 作成者本人と、紐づけ済みのサブアカウントの投稿だけが残ります。
- ほかの人が投稿した場合、その投稿はBotにより削除されます。
- 閲覧できる範囲は、日記フォーラムのDiscord権限に従います。

### VIP日記 — 50,000krm

- Botによる他ユーザー投稿の削除は行われません。
- 閲覧・投稿できる範囲は、日記フォーラムのDiscord権限に従います。

> 本メン・鯖主・管理者の各ロールを持つ人は、通常日記・VIP日記を無料で作成できます。

## 通常日記をVIP日記にするには

通常日記を利用中の場合は、日記パネルの **「アップグレード」** を押してください。

- 料金は差額の **45,000krm** です。
- 新しいタイトルを入力できます。
- 本文を入力すると、日記スレッドに新しい投稿として追加されます。
- すでにVIP日記を利用中の場合、「アップグレード」は使えません。

## 3日間投稿がない場合

作成者本人または紐づけ済みのサブアカウントから **3日間投稿がない** 日記は、自動でクローズされます。

もう一度使いたいときは、日記パネルで **「通常日記」** または **「VIP日記」** を選び、タイトルと本文を入力して確定してください。同じ日記スレッドを再開できます。

> 通常日記では、ほかの人の投稿は継続判定に含まれません。

## 困ったとき

- 残高が足りない場合は、日記を作成・再開・アップグレードできません。
- 通常日記をVIP日記に変えたい場合は、通常日記の作成ボタンではなく **「アップグレード」** を使ってください。
